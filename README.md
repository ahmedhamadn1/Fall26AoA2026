# Sorting Algorithms – Empirical Analysis

## Contents
- `sorting_analysis.py`: implementations and benchmark program.
- `sorting_results.csv`: measured average execution times.
- `sorting_graph.png`: execution-time graph.
- `Major_Assignment_Sorting_Analysis.pdf`: written report.

## Requirements
- Python 3.8 or newer
- No third-party packages are required to run the sorting benchmark.

## Run
```bash
python sorting_analysis.py
```
The script tests Bubble Sort, Selection Sort, Insertion Sort, and Merge Sort on
input sizes 5, 10, 50, and 100. It uses reverse-sorted data and takes five
timed batches for each algorithm and size. Results are written to
`sorting_results.csv`.
